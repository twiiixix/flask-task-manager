# Flask Task Manager App

## Overview

A full-stack task management web application built with Python Flask and SQLite. Users can add tasks, mark tasks as complete, delete tasks, and persist data through a local database.

## Features

- Add new tasks
- Mark tasks as complete / incomplete
- Delete tasks
- Store tasks in SQLite database
- Clean responsive UI
- Persistent data after app restarts

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
